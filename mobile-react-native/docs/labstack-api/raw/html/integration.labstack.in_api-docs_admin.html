API for managing your account — updating the details on record for a user you have booked. Every call must include a valid ls-api-key header.

User

Update a user's gender and date of birth

Updates the gender and/or date of birth on record for an existing user, identified by the uniqueId they were booked with. uniqueId is required, and so is at least one of gender, dateOfBirth or age; when both dateOfBirth and age are given, dateOfBirth is used. Only what you send is changed: a gender or date of birth you leave out stays as it is on record, and other user details are not changed. Bookings and orders already placed for the user are not updated: one still in progress keeps the gender and date of birth it was placed with. The response returns the user's name, gender, date of birth and age as now on record; a gender, date of birth or age with nothing on record is null.
