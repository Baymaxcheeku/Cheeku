# Wiki banners

Header images for the eight Confluence space homepages (cheekuai.atlassian.net/wiki).
Brand palette (purple #5b4ef0, navy #14136b, lavender), Instrument Serif and Inter, mascot art from `assets/mascot` and `assets/care`.

Edit the text in `make.js`, then run `node make.js` from this folder. It writes `banner-<space>.png` at 2400x560.
Upload the new file to the space homepage and set it as the page header image.
