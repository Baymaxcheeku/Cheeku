# Where work goes

This repo holds the Cheeku app (`mobile-react-native/`). Two other products
live in their own repos. Use them every time, even for small changes.

## Landing page: Baymaxcheeku/landing_baymax

Every change to the landing page (cheeku.ai marketing site) is made and
pushed in https://github.com/Baymaxcheeku/landing_baymax. Do not change or
push landing page work in this repo; the old `landing/` folder here is no
longer where landing work goes.

## Cheeku Doctors (the ₹49 doctor web app): Baymaxcheeku/doctor_hub

Everything for the Cheeku Doctors web app, including "Cheeku Doctors for 49",
is built and pushed in https://github.com/Baymaxcheeku/doctor_hub. Do not
build it inside this repo.

If a session does not have the right repo attached, add it first (and ask the
owner to grant access if that fails) rather than falling back to this repo.

## Other rules

- No videos in this repo. Rendered videos are sent to the owner directly.
