## Rebuilding v2

These steps need Node 20 or later, Python 3.11, ffmpeg and Chrome or Chromium.

```bash
cd marketing/product-demo/v2
npm install
python3 -m venv .venv && . .venv/bin/activate && pip install kokoro-onnx soundfile numpy
mkdir -p models && curl -L -o models/kokoro-v1.0.onnx https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/kokoro-v1.0.onnx \
  && curl -L -o models/voices-v1.0.bin https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/voices-v1.0.bin

python vo.py         # voice-over lines from script.json into public/vo/
python timeline.py   # scene timings around the measured lines, into src/timeline.json
python music.py      # the score, music.wav
python mix.py        # voice + ducked music + sound effects, public/mix.wav
npx remotion studio  # preview and scrub
npx remotion render src/index.ts Demo out/demo.mp4 --codec=h264 --crf=17 --audio-bitrate=320k
```

- **Changing a line:** edit `script.json`, then run `vo.py`, `timeline.py`, `music.py` and `mix.py` again, so the timings and the score follow the new lengths.
- **Changing a screen:** edit the scene in `src/scenes/`. `s1.tsx` covers the hook to planning, `s2.tsx` pregnancy to the fever, and `s3.tsx` care, the engine and the close.
- **Where the design comes from:** colours, fonts, mascot, avatars and care art are copied from `mobile-react-native`, so update them there first.
- **Browser path:** `remotion.config.ts` points at the sandbox's headless Chromium. Remove that line on a laptop and Remotion uses its own browser.

The voice is Kokoro-82M (Apache 2.0). The score and sound effects are original and generated by `music.py` and `mix.py`, so there are no third-party music licences.
